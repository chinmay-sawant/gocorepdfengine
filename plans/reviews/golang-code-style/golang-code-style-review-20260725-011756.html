Executive summary

Stdlib-only PDF engine with a clean package map and solid leaf helpers. Style is strongest on philosophy (zero deps, no reflect, sound value-vs-pointer choices) and weakest on function shape: multi-hundred-line assemblers, 5–7 parameter APIs, and one-line call sites that break the 4+ args rule.

Control flow is generally good at the leaf level (early returns, sensible switch/range), but the dual generate paths bury happy-path font emission under nested mode/fallback branches.
