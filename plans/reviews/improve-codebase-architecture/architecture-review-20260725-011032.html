Deepening candidates

1. Collapse dual assemblers

Strong in-process

engine/engine.go · engine/document.go

Before — two shallow-locality procedures

Generate
font · ICC · UA wrap · structure · catalog
subset: yes
GenerateDocument
font · ICC · UA wrap · structure · catalog
subset: no · product path

After — one deep assembly module

interface: assemble(DocumentConfig)
font embed
profile apply
structure attach
catalog build
Generate / GenerateDocument = thin adapters

Problem

Policy graph written twice; subset already drifted.

Solution

One assembler; both entry points call it.

Wins

  • locality: assembly bugs concentrate
  • leverage: one path, two callers
  • delete duplicated blocks
